# 韩语阅读助手 (Korean Reading Helper)

一个浏览器扩展：阅读韩文网页或 PDF 时，**双击或选中**文字，选区右上角会浮出插件图标，点它即调用 AI（DeepSeek / OpenAI / 兼容接口）获得单词和语法解析，并一键加入**生词本**或**语法笔记本**，之后可导出为 Notion 风格的 PDF。

## 功能

- **划词解析**：双击/选中韩文，选区右上角浮出插件图标，点图标才弹出悬浮窗并开始解析
  - 选中本身不会调用 AI，避免误触浪费 API 额度；同一内容缓存命中时直接显示，也不再消耗额度
  - 单词：词性、原形、罗马音、释义、活用拆解、例句
  - 句子：整句翻译 + 逐词解析（每个词/助词/词尾都有说明，语法点直接并入对应的词）
- **生词本**：一键加入，导出 PDF，可选 2 列（韩文｜中文）或 4 列（韩文｜空白｜中文｜空白，便于默写）
- **笔记本**：保存完整解析，导出简洁的 Notion 风格 PDF，连续排版
- **PDF 阅读**：自带 PDF 阅读器（基于 PDF.js），可自动接管浏览器里的 PDF，也可拖入本地文件
- **自选模型**：DeepSeek、OpenAI，或任何 OpenAI 兼容的中转地址

## 安装

目前支持 Chrome、Edge 等 Chromium 内核浏览器（Manifest V3）。

1. 下载本仓库（`Code → Download ZIP`，或在 [Releases](../../releases) 下载打包好的 zip）并解压
2. 打开 `chrome://extensions`，开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择解压后的文件夹
4. 点击工具栏里的插件图标，进入「设置」，选择服务商并填入你自己的 API Key，点「测试连接」

## 使用

- 在任意网页上选中韩文，选区右上角会出现插件图标，点它才弹出悬浮窗并开始解析；Esc 或点击空白处关闭图标与悬浮窗
- 在 PDF 页面点击插件图标，可切换到本插件的 PDF 阅读器；也可在设置里开启「自动接管 PDF」
- 本地 PDF：打开 PDF 阅读器后把文件拖进去，或使用 `file://` 地址（需在扩展详情页开启「允许访问文件网址」）
- 导出：插件图标 → 生词本/笔记本 → 导出 PDF，在打印窗口目标选「另存为 PDF」，建议取消页眉页脚、勾选背景图形

## 隐私

- 你的 API Key 和所有生词、笔记**只保存在本机浏览器的扩展存储中**，作者不会收集任何数据。
- 选中的文字及其所在上下文（最多约 300 字）会发送给**你自己选择的 AI 服务商**用于解析，请遵守对应服务商的隐私条款。
- 开启「自动接管 PDF」会请求访问所有网站的权限，仅用于识别并读取 PDF，不读取其他页面内容。

## 项目结构

```
manifest.json      扩展清单（Manifest V3）
background.js      后台：调用 AI 接口、PDF 接管
content.js         网页内：取词、选区图标与解析悬浮窗（Shadow DOM 隔离样式）
manager.*          生词本 / 笔记本 / 设置页
export.*           PDF 导出页（Notion 风格，浏览器打印为 PDF）
viewer.*           内置 PDF 阅读器
lib/               PDF.js 及其资源文件
icons/             图标（icon.svg 为矢量原稿）
```

## 已知限制

- 扫描版（纯图片）PDF 没有文字层，无法选中取词，需先做 OCR
- AI 返回内容可能有误，学习时请自行核对
- 暂不支持 Firefox / Safari
